# people-database-go

Консольное приложение на Go для хранения базы людей в текстовом файле (`people.txt`). Поддерживает добавление, поиск, просмотр статистики и поиск по городу — без использования базы данных, только через чтение/запись файла.

## Возможности

- **Показать базу** — вывод всех записей
- **Добавить человека** — ввод имени, возраста и города; после добавления база сразу перезаписывается в файл
- **Найти человека** — поиск по точному совпадению имени
- **Статистика** — самый молодой человек в базе, самый возрастной, средний возраст
- **Поиск по городу** — вывод всех людей из указанного города

## Стек

- **Go** (только стандартная библиотека: `os`, `strings`, `strconv`, `fmt`)
- Хранилище — обычный текстовый файл `people.txt` в формате CSV-подобных строк: `Имя,Возраст,Город`

## Формат файла people.txt

```
Slave,21,Tokio
Bob,18,London
Kate,25,Paris
John,30,Berlin
```

Каждая строка — одна запись, поля разделены запятой. При запуске программа построчно читает файл, разбивает по запятой и собирает срез структур `Person`. Строки с некорректным числом полей или нечисловым возрастом пропускаются, чтобы не уронить программу.

## Установка и запуск

```bash
git clone https://github.com/TheOracleCorporation/people-database-go.git
cd people-database-go
```

Перед первым запуском обязательно создайте файл `people.txt` рядом с исходником (программа не создаёт его автоматически, см. "Известные ограничения" ниже). Пример содержимого — см. раздел выше.

```bash
go run main.go
```
